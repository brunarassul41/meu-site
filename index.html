Formação em Informática

HTML é uma linguagem utilizada para estruturar os elementos de um website. A sua aprendizagem ajudou-me a compreender a função das etiquetas e a forma de organizar textos, imagens e links numa página.

A linguagem CSS permite definir o estilo visual de uma página, incluindo o fundo, as cores, as dimensões e o alinhamento dos elementos. Aprender estas duas linguagens foi importante para dar os primeiros passos na criação de websites.
